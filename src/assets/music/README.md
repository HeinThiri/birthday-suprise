# Background music

Drop a single audio file here named `birthday.mp3` (or update the path
in `src/app/core/services/config.service.ts` -> `musicSrc`).

Royalty-free birthday music sources:

- https://pixabay.com/music/search/happy%20birthday/
- https://www.bensound.com/
- https://freemusicarchive.org/

If no file is present, the music toggle simply does nothing — the site
otherwise works as expected.
